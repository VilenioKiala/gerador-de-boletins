# Gerador de Boletins

[English](README.en.md) | [Português](README.md)

**Gerador de Boletins** é um projecto focado na criação de boletins escolares para as escolas Angolanas (de onde eu venho). Ele utiliza os dados inseridos pelo usuário no terminal, dados como: o nome do estudante, a classe, ano lectivo e as disciplinas com as suas respectivas notas.

O programa é completamente no terminal e gera um ficheiro excel no final com o Boletim.

## Requisitos

Para rodar este programa, você precisará das seguintes:

- Windows;
- Python;
- Git (opcional);
- Winrar (opcional, se você não possue git)

## Como instalar

Aqui vou lhe ensinar, passo-a-passo como instalar este projecto:

### Passo 1: Baixar este repositório

Baixe este repositório clicando em **<> Code** e **Download Zip** e extraia-o em qualquer pasta. ou, se você possue o Git instalado no seu computador, abra o seu terminal (cmd no Windows), e insira este comando na pasta que deseja salvar o projecto:
`git clone https://github.com/VilenioKiala/gerador-de-boletins.git`

### Step 2: Instale todos os pacotes necessários

Com o **Python** instalado, abra o terminal na pasta do projecto e rode este comando:
`pip install -r requirements.txt`

### Tudo certo!

Agora que você tem tudo certo, vou lhe ensinar agora a como usar o programa.

## Como usar

Na pasta do projecto, abra o ficheiro **launcher.bat** ou simplesmente **launcher** para inicializar o programa, responda todas as perguntas e o programa no final irá gerar um ficheiro do Excel contendo o Boletim gerado no padrão de Angola e preparado para impressão.
